# Tintifier Clone 🎨

A simple browser-based image tinting tool.

## Features
- Upload image
- Apply color tint
- Adjust intensity
- Download result

## How to Use
1. Upload an image
2. Pick a color
3. Adjust intensity
4. Click "Apply Tint"
5. Download your image

## Deployment (GitHub Pages)
1. Upload files to a GitHub repo
2. Go to Settings → Pages
3. Select branch: `main`
4. Save
